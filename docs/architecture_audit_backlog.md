# Architecture Audit Backlog

This backlog records non-critical findings discovered during the P0/P1 core stabilization pass. These items were not changed because they do not block the stabilization gate and broad refactoring is outside this phase.

| ID | Area | Severity | Evidence | Reproduction | Impact | Suggested next step |
|---|---|---|---|---|---|---|
| ARCH-P2-001 | Configuration parsing | P2 | `tools/atlas_orchestrator.py::_load_json_or_default` returns a default after any parse exception without exposing the parse error. | Provide malformed JSON to a caller that uses this helper. | A malformed optional state file can look identical to an absent file. | Return structured warning metadata at the existing caller boundary; do not change fallback behavior without compatibility tests. |
| ARCH-P2-002 | Registry discovery | P2 | `tools/atlas_run.py::_load_skill_registry` skips malformed `skill.json` files after a catch-all exception. | Add an invalid skill manifest to a temporary governed fixture. | A broken skill can disappear from discovery without an explicit diagnostic. | Surface a non-blocking registry warning and cover it with a fixture test. |
| ARCH-P2-003 | JSONL observability | P2 | `tools/error_pattern_analyzer.py` and `tools/project_phase_resolver.py` ignore malformed JSONL records. | Place a malformed line between valid runtime-state records. | Analysis remains available, but corrupt records are not counted or reported. | Add a skipped-record count to existing reports while preserving tolerant reads. |
| ARCH-P3-001 | Temporary-file cleanup | P3 | `tools/atlas_codex_executor.py` ignores `OSError` while deleting the last-message temp file. | Force deletion failure in the existing cleanup test. | Execution result is preserved, but a temporary file may remain. | Add a cleanup warning field if operational evidence shows residue is recurring. |
| ARCH-P2-004 | Local browser environment | P2 | Python 3.14 can import Playwright but cannot load `greenlet._greenlet`; the recorded Python 3.13 temporary runtime no longer exists. | Run the opt-in real-browser smoke under the current local Python 3.14 installation. | Local real-browser evidence is blocked; the manual Python 3.13 workflow remains the reproducible path. | Recreate an isolated Python 3.13 dev environment when local browser work is required; do not install global packages. |
